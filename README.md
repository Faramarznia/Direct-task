# دایرکت · افزودن و مدیریت دستگاه

نمونه تعاملی موبایل برای پنل باشگاه مشتریان دایرکت: افزودن دستگاه ثبت شماره مشتری، مدیریت دستگاه‌ها در یک یا چند شعبه، و ساختاری که انتخاب گروه مخاطب را هنگام ارسال پیام ممکن می‌کند.

- **نمونه آنلاین:** https://faramarznia.github.io/Direct-task/
- **مستند تصمیم‌های طراحی و گزارش AI:** https://faramarznia.github.io/Direct-task/docs.html
- فایل‌ها: `index.html` (نمونه تعاملی) و `docs.html` (مستند)

## اجرا

بدون نصب، build یا اینترنت:

1. فایل `index.html` را در مرورگر باز کنید.
2. یا با یک سرور ساده اجرا کنید:
   ```bash
   npx serve .
   # یا
   python3 -m http.server 8000
   ```
   و آدرس `http://localhost:8000` را روی گوشی یا مرورگر باز کنید.

روی دسکتاپ، نمونه داخل قاب گوشی نمایش داده می‌شود و پنل سناریوها و یادداشت طراحی هر صفحه کنار آن است. روی موبایل (عرض ۳۶۰ تا ۴۳۰ پیکسل)، نمونه تمام‌صفحه است و راهنما از نوار بالای صفحه («سناریوها و راهنما») باز می‌شود.

### فونت‌ها

پینار برای عنوان‌های نمایشی (نسخه FD با ارقام فارسی) و یکان‌بخ برای عنوان‌ها و متن. فقط وزن‌های استفاده‌شده در `assets/fonts/` آمده‌اند:

```
assets/fonts/yekanbakh/YekanBakh-{Light,Regular,SemiBold,Bold,ExtraBold,Black}.woff2
assets/fonts/pinar/Pinar-FD-{Medium,Bold,ExtraBold,Black}.woff2
```

### انتشار روی GitHub Pages

نسخه آنلاین از شاخه `gh-pages` منتشر می‌شود که همان محتوای شاخه کار است. برای به‌روزرسانی نسخه آنلاین پس از هر تغییر:

```bash
git push origin HEAD:gh-pages
```

## سناریوها

| # | سناریو | لینک مستقیم |
|---|---|---|
| ۱ | افزودن اولین دستگاه (تک‌شعبه، بدون دستگاه) | `index.html?s=1` |
| ۲ | افزودن و مدیریت دستگاه دوم | `index.html?s=2` |
| ۳ | مدیریت دستگاه‌ها در دو شعبه | `index.html?s=3` |
| ۴ | پشتیبانی از انتخاب مخاطب هدف | `index.html?s=4` |
| ۵ | تغییر اطلاعات دستگاه و اثر آن | `index.html?s=5` |

### کدهای آزمایشی دستگاه

| کد | نتیجه |
|---|---|
| هر کد ۸ رقمی دیگر | دستگاه جدید، موفق |
| `1111 1111` | کد پیدا نشد |
| `2222 2222` | متصل به حساب دیگر |
| `3333 3333` | قطع ارتباط (بار دوم موفق) |
| کد یک دستگاه موجود | قبلاً اضافه شده |

داده‌ها ساختگی‌اند و در `localStorage` مرورگر ذخیره می‌شوند. «بازنشانی» در پنل راهنما، داده سناریوی فعلی را برمی‌گرداند.

## ساختار فایل‌ها

```
index.html            پوسته اپ و پنل راهنما
docs.html             تصمیم‌های طراحی، مسیر کاربر، مثال داده‌ای، گزارش AI
assets/css/fonts.css  پینار (نمایشی) و یکان‌بخ (عنوان و متن)
assets/css/app.css    توکن‌ها و اجزای سیستم طراحی (برگرفته از direct.ir)
assets/js/icons.js    آیکون‌ها و تصویرسازی‌های SVG
assets/js/data.js     داده ساختگی سناریوها
assets/js/app.js      وضعیت، مسیریابی، صفحه‌ها، برگه‌ها و جریان‌ها
assets/fonts/         فایل‌های woff2 پینار و یکان‌بخ
.nojekyll             انتشار مستقیم فایل‌ها روی GitHub Pages بدون پردازش Jekyll
```

بدون فریم‌ورک و بدون وابستگی خارجی، تا روی هر میزبان استاتیک (مثل GitHub Pages) یا مستقیم از فایل اجرا شود.
